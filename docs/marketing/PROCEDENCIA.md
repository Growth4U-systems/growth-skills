# Procedencia de las 25 skills de marketing

Fuente pública de esta integración: [Growth4U-systems/marketing-skills-25](https://github.com/Growth4U-systems/marketing-skills-25/tree/4d54e83f25e37b2ee467f6cd216ec70211d1e228), commit `4d54e83f25e37b2ee467f6cd216ec70211d1e228`. Se preservan las 25 identidades y las licencias locales, trasladadas a `skills/<nombre>/`.

Esta edición reescribe los procedimientos para profundizar decisiones y tratamiento de límites, completa contratos/ejemplos y añade casos de aceptación y fixtures. Las cuatro skills preexistentes de GrowthSkills se mantienen sin cambios; no se atribuyen al nuevo kit ni se declara que las cubra su suite.
